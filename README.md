# Modelo-GARCH-Analisis-de-volatilidad-Dolar-Usd
Desarrollo de un modelos econométricos sobre series de tiempo para manejo de volatilidad, desarrollado como parte de un curso de herramientas para el análisis del mercado de capitales.
Lenguaje manejado: R
Datos recuperados: Yahoo Finance, corte temporal para probar el impacto de un shock de cambio politico en el país (Transición de gobierno Petro a gobierno De la Espriella)
Proposito educativo, susceptible a actulizaciones y recomendaciones.
